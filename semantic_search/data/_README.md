# Extra documents

Drop any `.md` or `.txt` files here and they will be indexed alongside the four
project READMEs the next time the hub starts.

For everything else — PDFs, Word, Excel, PowerPoint, HTML, code — use the
**Document Library** tab in the Semantic Search project instead. It extracts
the text, files them in `library/`, and indexes them for search.

This folder used to hold copies of the project READMEs. It no longer does: the
engine reads the live README files directly, so the index can never fall out of
step with the documentation it describes.
